Pipeline rule

Every W8 / scoped report prompt must live under prompts/ in this pack. Chat paste is not enough. w8-prepare refreshes notebooklm-all-prompts.

Note Role
notebooklm-all-prompts Canonical archive — every prompt in one file
notebooklm-prompt-set W8 T1–T5 + Briefing + Study Guide + data-table

How to use

  1. Open notebooklm-all-prompts for the full text.
  2. For late-added sources, use notebooklm-new-sources with --source-ids.
  3. After adding new prompts in chat, run python -m one_day_mastery prompts-sync --slug dcsa or re-run w8-prepare.

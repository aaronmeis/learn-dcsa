Block 2: Mental models

Time: 45 minutes
Goal: How experts chunk the domain
Pack: DCSA (Defense Counterintelligence and Security Agency) (dcsa)

Focus from mind map

  • Dual-track lock — FCL and PCL feed each other
  • Clock vs quality — Day 20/45 punish incomplete packages harder than slow complete ones
  • FOCI as schedule risk — mitigation (SCA/SSA/Proxy, etc.) can add months; 15% SF 328 threshold expands who must explain foreign revenue
  • Whole person vs checklist — SEAD 4 is cumulative/contextual
  • CMMC ≠ FCL — uncleared CUI floor ≠ NISP classified ATO (cross-link sibling pack)
  • Four domains as the operating-model layer cake

Sources

  • [S2] FCL Orientation Handbook — clocks + package quality
  • [S4] SF 328 Industry Information Paper — Q7b 15%
  • [S5][S6] CDSE IS140 / IS142
  • [S9] Continuous vetting update (PVQ every 5 years; PR eliminated for NISP contractors)
  • [S13] DAAPM v2.2 — IS authorization under RMF
  • CMMC sibling mission (contrast only)

Actions

  1. Capture these five named models in a table: When to use / How / Failure mode. | Model | When | How | Failure mode | |-------|------|-----|--------------| | Dual-track lock | Any “how do we get cleared?” ask | Map FCL sponsor → KMP PCLs → usable facility | Treating badge chase as independent of FCL | | Clock vs quality | Post–welcome-email planning | Day 20 package complete; Day 45 KMP fingerprints queued | Incomplete first package → return cycle | | FOCI as schedule risk | Foreign ownership, revenue, partnerships | SF 328 disclosure + mitigation path | “No FOCI forever” or ignoring 15% Q7b | | Whole person (SEAD 4) | Adjudication / self-assessment prep | Thirteen guidelines, contextual | Checklist yes/no theater | | Two walls (CMMC ≠ FCL) | Cloud / CUI / GCC High confusion | CMMC floor vs NISP/DAAPM wall | Equating GCC High with Secret FCL |
  2. Sketch how the four domains hang off DCSA (one box each).
  3. One sentence: why a non-possessing FCL still needs the dual-track lock.

Retrieval check

Question

Which mental model do you reach for first when a lab says “we’ll just get GCC High and then we’re cleared”? Why?

%% fold answer after attempt %%

Answer cues

Two walls / CMMC ≠ FCL: GCC High may support CUI architectures; it does not confer FCL or authorize Secret/TS. Then dual-track lock: FCL still needs GCA/prime sponsorship in NISS + cleared KMPs.

Exit criteria

  • Five models captured with when/how/fail
  • Four-domain sketch done
  • Non-possessing one-liner written

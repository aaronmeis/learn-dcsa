Block 8: Design review and teach-back

Block 8 — design review teach-back: dual-track swimlane, FOCI gate, DAAPM/RMF, CMMC≠FCL≠ATO.

Time: 30 minutes · Goal: Defend the dual-track architecture to a skeptical architect

Focus from mind map

  • Whiteboard: dual-track swimlane + FOCI branch + IS authorization branch
  • Output: one-page “lab with foreign partners” decision brief under SF 328 (2025)
  • Question list of remaining [verify] / silence items

Sources

  • All views · MISSION success criteria · quiz-bank · cheatsheet

Actions (tied to views)

  • 10-minute teach-back: Draw dual-track swimlane (FCL ↔ PCL), FOCI branch, DAAPM/RMF branch — from conceptual altitude first, then name systems only if challenged.
  • Deliver the one-page brief: fictional lab with foreign partners — sponsorship path, SF 328 Q7(b) 15% test, whether possessing FCL is required, AI tooling ban on PII.
  • State three design decisions you defend: (1) no self-sponsor; (2) FOCI is a branch; (3) CMMC ≠ FCL ≠ ATO.
  • State one decision you would not defend without more primary text (e.g., exact resubmit counts; DISS product name).
  • Answer quiz-bank without notes.
  • Read remaining [verify] / silence list aloud (DISS stack; Day-20 attempt count; official DCSA AI inventory; handbook resubmit language).

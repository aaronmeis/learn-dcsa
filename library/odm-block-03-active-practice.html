ODM day blocks

Block 3: Active practice

Time: 90 minutes
Goal: Deliberate practice with feedback
Pack: DCSA (Defense Counterintelligence and Security Agency) (dcsa)

Focus from mind map

  • Dual-track swimlane: GCA/prime → NISS → Day 20/45 → KMP PCLs → FCL grant
  • Package completeness drill (DD-441, SF-328, ownership, KMP)
  • Tier/SEAD sorting + FOCI / SF 328 15% scenarios
  • Kill myths: self-sponsor · CMMC/GCC High = FCL · SF 328 is one-and-done

Sources

  • [S2] FCL Orientation Handbook
  • [S4] SF 328 Industry Information Paper (15%)
  • [S10] How to Get a Facility Clearance (Bennett FSO)
  • [S11] DON OSBP Small Business Webinar — DCSA
  • mindmap · cheatsheet

Actions

  1. Swimlane (30m). Draw left-to-right: Need for classified access → GCA or cleared prime sponsors in NISS → Acceptance / welcome email (Day 1) → Day 20 package → Day 45 KMP investigation requests + fingerprints → KMP PCLs adjudicated → FCL granted → continuous obligations (ISR relationship, SF 328 updates, CV). Annotate who owns each step.
  2. Package completeness drill (25m). For a fictional non-possessing startup subcontracting to a cleared prime, mark each item Ready / Missing / Needs FOCI narrative: - Articles of incorporation / formation docs - Ownership / org chart (beneficial owners) - DD Form 441 Security Agreement - SF 328 (foreign interests) — flag if foreign research revenue ≈ 16% of proceeds - KMP list with roles (FSO, ITPSO, officers with fiduciary duties) - Fingerprint / investigation-request readiness for each uncleared KMP
  3. Sort these vignettes (write FCL-path / PCL-path / FOCI-risk / wrong-wall / ask-ISR):
  4. Company uploads SF-86s for staff before any sponsorship exists
  5. University lab has 18% foreign grant revenue; SF 328 last filed under 30% rule
  6. Startup “self-sponsors” FCL in NISS with no GCA letter
  7. Cleared prime sponsors sub; Day 18 package missing ownership chart
  8. Engineer needs Secret for prime site; company is non-possessing FCL
  9. Program office says “get GCC High then you’re Secret-ready”
  10. KMP fingerprints scheduled for Day 50 after welcome email
  11. Foreign parent holds 40% voting interest; mitigation not started
  12. Possessing FCL site wants classified IS — points only to CMMC L2
  13. Continuous vetting hit; PVQ cadence vs old periodic reinvestigation
  14. Grade against cheatsheet; list two corrections.

Retrieval check

Question

A welcome email arrived 30 days ago. Package is still incomplete; KMP fingerprints not submitted. Which clocks are already breached, and what is the main choke point DCSA talks about?

%% fold answer after attempt %%

Answer cues

Day 20 package clock breached; Day 45 KMP investigation/fingerprint clock is 15 days away (or breached if past Day 45). Main choke: incomplete first packages returned — documentation quality, not “speed alone” [S2][S10][S12].

Exit criteria

  • Swimlane drawn with owners
  • Package drill scored Ready/Missing/Needs narrative
  • All 10 vignettes sorted with one-line reasons
